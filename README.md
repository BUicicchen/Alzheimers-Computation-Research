# Biophysical modeling of excitation/inhibition imbalance in Alzheimer's disease
This research focuses on a two‑layer rate‑based neural model of early and higher visual areas with feedforward, feedback, and recurrent connections to examine how excitatory/inhibitory (E/I) balance shapes visual motion perception in Alzheimer's Disease.

This repository contains the code that makes up our neural model, as well as the experimental parameters we performed.

### Prereq:
- All code are written in [MATLAB](https://www.mathworks.com/products/matlab.html), download and open the files on the software
    - Install "statistics and machine learning toolbox"
